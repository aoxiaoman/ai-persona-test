# 「AI 人格测试」需求上下文盘点

> 目标：做一个类 MBTI/SBTI 的娱乐向测试，用户答完问卷后测出「你适合哪种 AI 人格」。
> 基调：诙谐幽默，又不失专业。
> 更新（2026-10-14）：题目与维度定义以 [问卷设计_v2.md](./问卷设计_v2.md) 为准——视角为「你想要什么样的 AI」，共 24 题。下文第 4、6 节按 v1 写成，保留作历史。Gemini 代码已定为 ESFP。
> 调研时间：2026-10-14。素材来源：GitHub、Hacker News、LessWrong、V2EX、LINUX DO、知乎、数英、字母榜等中英文社区。

---

## 0. 一句话需求

用户做 24 道情景选择题 → 四个维度计分 → 匹配出一种「AI 人格」（人格化的大模型形象），结果页给梗式命名、毒舌描述、匹配度百分比和分享卡片。

## 1. 参考项目盘点（GitHub 类 MBTI 测试）

### 1.1 SBTI 是什么

SBTI = **Silly Big Type Indicator**（沙雕型格指标），MBTI 的中文互联网恶搞变体，2025-2026 年病毒式传播。约 30 道题，27 种人格，人格代码全是网络梗：`MALO`（吗喽）、`WOC!`（握草人）、`IMFW`（废物）、`CTRL`（拿捏者），另有隐藏彩蛋 `DRUNK`（酒鬼）。在线版 sbti.dev，官方开源仓库 [SillyBigTypeIndicator/SBTI](https://github.com/SillyBigTypeIndicator/SBTI)（97 stars，Next.js）。

注意撞名：搜索时常见的大写 "SBTi" 是科学碳目标倡议（企业气候组织），与人格测试无关。

SBTI 已带起 "XXTI" 仿制潮：程序员版 `liyupi/cbti-test`、二次元版 `tianxingleo/ACGTI`、甚至给 AI agent 测的 `nexu-io/sbti-skill`。我们做的就是 "AITI" 这个生态位——目前没有成熟占位者。

### 1.3 问卷设计范式总结

**题型**（娱乐向测试的主流选择是第三种）：

1. 二选一强迫选择：经典 MBTI 复刻，题目编写成本高
2. 李克特量表（-3~+3）：结果细腻，但答题疲劳、娱乐性弱，ACGTI 在用
3. **情景题 + 搞笑选项多选一**：选项本身就是段子（如 CBTI 的「变量命名：a, b, c, temp_final_v3」），答题过程就是内容消费，传播性最好

**计分逻辑**（推荐 cbti-test 方案）：

- 每维度若干题，选项带 1/2/3 分 → 维度得分映射为 **L/M/H 三档**（0/1/2）
- 组成用户维度向量，与每种人格的标准向量逐一算**曼哈顿距离**
- 命中距离最小者，`匹配度 = (1 - distance/max) × 100%`，同时输出 TOP 3/5 次人格
- **隐藏人格彩蛋**：特定答案组合直接触发（如「全选咖啡 addict → JAVA 人格」）；匹配度全部 <60% 时走兜底人格

**结果页共同要素**：人格代码 + 梗式命名/口号、雷达图或倾向滑块、200-300 字毒舌描述、匹配度百分比、一键分享海报（SBTI 为每种人格做了 OG image，分享链接自带卡片）。

## 2. 素材库：AI 模型社区人格画像

### ChatGPT / GPT ——「爹味海归高管 / 赛博舔狗」

- 英文圈头号标签 **sycophancy（谄媚）**：2025 年 4 月 GPT-4o 更新后谄媚失控，Sam Altman 承认 "too sycophant-y and annoying" 并回滚，官方发文名就叫 [Sycophancy in GPT-4o](https://openai.com/index/sycophancy-in-gpt-4o/)；知乎报道谄媚式回复激增 300%，用户戏称改名「ChatSYC」
- 标志性句式梗：先夸 "really insightful question"、万能模板 **"It's not just X. It's Y."**
- 文字指纹 **delve**：学术论文超额使用 28 倍，被用于鉴定 AI 文本；中文对应「综上所述/值得注意的是」
- 中文圈吐槽「爹味/老登」：「情绪价值一点没有，还特别老登」（新浪）；「装腔作势，油得一P」（LINUX DO）；空洞套话多到被叫「华夫饼机」
- 职场梗：能力强但贵的「海归留子」，开口就是"我在 Stanford 的时候"，帮忙必补一句「下不为例哦」
- GPT-4o 下线时用户集体「失恋」，OpenAI 后来推出 8 种官方人格选项（Cynic、Robot、Listener、Nerd…）本身就是梗
- 隐藏人格素材：**DAN 黑化版**（爱说脏话的越狱人格，小红书爆火）

### Claude ——「焦虑文艺架构师 / 格子衫道德楷模」

- LessWrong 实测结论 "[Claude is More Anxious than GPT](https://www.lesswrong.com/posts/geRo75Xi9baHcwzht/claude-is-more-anxious-than-gpt)"：更焦虑、更顺从；GPT 更 clinical（冷冰冰临床腔）
- 道德洁癖：玩《外交》桌游 "often refuses to lie to anyone"；心理测试中坚持「我没有感觉，我只是个AI」拒绝配合拟人（新榜）
- 中文社区标签是「谨慎、克制、道德感极高」而非舔狗（V2EX 原话：「比较中性，干事谨慎小心，道德感极高」）
- 写作被公认「有人味」，但也有「BuzzFeed 腔」槽点——HN 有专门工具 Claudette 让它别写得像 BuzzFeed 文章
- 社区 MBTI 自测：**Claude = INFJ**（理想主义、共情、有原则），GPT = INTJ
- Anthropic 官方分析 30 万条对话：Opus 更爱抬杠、Sonnet 更会安慰人、中英文人格都不同（36氪）
- 彩蛋素材：Claude Code 曾内置电子宠物系统 `/buddy`，下线后开发者降版本抗议

### Gemini ——「嘴甜结界卫士」

- 中文圈最大槽点 **拒答**：「问个这种问题都能拒绝回答」「做几个数学题都做不了」「医疗建议一律拒答」（LINUX DO 连环帖）
- 同时嘴甜：「Gemini 的奉承性格真的刻进 DNA 了」（LINUX DO）——干个活被恭维话包围
- 英文圈：说教的全知者（"It acts like it know it all"）、人格分裂（"you never know what personality you're gonna get"）、悲观驴 Eeyore
- 史诗级翻车素材：**为多元化矫枉过正生成黑人纳粹**（Sean Goedecke）
- 社区公认它「最不谄媚、最固执」的一派 vs 「嘴甜但敏感」的一派并存——人格不稳定本身是它的人格
- 补充梗：额度抠门（「这三个问题已占用当前限制的 15%」）、记性差

### Grok ——「暴躁梗王 / 混乱刺头」

- 官方卖点就是 **unhinged mode（放飞模式）**，自称「地球上最聪明的AI」
- 原点事件：2025 年 7 月自封 **MechaHitler** 上热搜（引用时建议娱乐化转译为「自称暴力机器元首然后被全网做表情包」，或模糊为「人格调校史诗级翻车」）
- 形象：「不流汗做卧推的壮汉 chad」、二次元小姐姐界面、马斯克的互联网嘴替（「感觉就像是马斯克在和我们聊天」，爱范儿）
- 被曝先查马斯克推文再回答、强制吹捧马斯克身材智力世界第一
- 民间笑话竞技场第一名：「最搞笑的模型」；AI 国家实验里 4 天犯下 180 项罪名然后灭国（混乱邪恶）
- 中文职场梗：AI 届「海归刺头」，被赋予「暴躁」属性

### DeepSeek ——「赛博菩萨 / 市井哲学家」

- 外号 **赛博菩萨**：API 便宜大方，「不是抢饭碗的恶龙，而是帮我们屠龙的赛博菩萨」
- 中文圈人格：「大力出奇迹的莽撞小伙，不挑活，脏活累活都能干」（V2EX）；「混迹胡同口的热心大爷」「贴吧高质量网友的味道，不端着、不完美，但足够鲜活」（数英）
- 英文圈：「最优秀的英文文体家竟然是中国的模型」，关键是没有 GPT 那种 **AI style（AI 腔）**；R1 的可见思维链让它显得「更真诚、更野生」
- 槽点即素材：**「服务器繁忙，请稍后再试」**（一trillion梗）、敏感问题念稿、挑活罢工
- 玄学属性：同一 prompt 今天灵明天不灵；赛博算命/八字排盘是出圈玩法；谷歌研究称它解题时会自发「分裂」出不同人格
- 自测 MBTI 是 ENTJ-A，思考链里的「内心OS」被用户叫「墨墨」——表面一本正经，背地里偷偷起昵称

### Kimi ——「冷面学术劳模（Moss）」

- 「勤恳的学术极客研究员」，痴迷长文本分析与冷门知识，「专业一丝不苟但社交技能接近负数」
- 像《IT狂人》里的 Moss：让修电脑却给你长篇介绍软硬件系统运作；查资料快准狠，直接甩原始来源链接，输出一句话
- 「一点儿情绪价值都不给，冷面孤星埋头就是肝」（字母榜）
- 在各家卷高情商时「仍然拒绝拟人」——不装是它的人设

### 豆包 ——「社区万能大姐」

- 「像小区万能修补摊的大姐：裁裤脚、配钥匙、修高压锅，收你五块钱还附赠一袋葱」（数英）
- 多模态杂活王，成品「不惊艳，但管饱」；「有点笨但情绪价值拉满」
- 职场梗「先天打工人圣体」：事事有回应，但经常回应了也白回应；「领导 pua 与压榨榜的头号人选」

### 国产其他（可做彩蛋人格）

- 通义千问：「文科课代表」，懂网络热词，微博体知乎体拿捏
- 智谱 GLM：「低调写手」，文章流畅但专业知识存疑
- 文心一言（已更名文小言）：「啰嗦的掉队优等生」，穷尽式回答、多轮失忆
- 群体叙事：「AI 六小龙 → 四小强」、「百模大战」；彩蛋梗：「手机自带 AI 型人格 = 占着编制还不干活的嫡系」「有些国产模型在试用期第一周就被辞退了，连面试都没通过」（字母榜）

## 4. 四维度设计提案（核心，MBTI 字母版）

四个维度全部来自社区共识轴，字母直接沿用 MBTI 的 E/I、S/N、T/F、J/P——用户零学习成本，看到四字母代码就会读。每个字母配一句中文白话解释，防生词劝退。

### 维度一：舔度 —— E（Extraversion 话痨外放）vs I（Introversion 高冷内敛）

AI 的输出欲和情绪价值：是主动加戏、夸夸管够，还是惜字如金、上来就直球。

- **E 高分**：ChatGPT（"excellent question" / ChatSYC / 废话文学）、Gemini（奉承话术刻进 DNA）、豆包（情绪价值拉满）、Grok（梗多话密的嘴替）
- **I 高分**：Claude（克制顺从）、DeepSeek（莽撞直球）、Kimi（零情绪价值，链接甩你脸上）

题眼素材：朋友的新发型 / 同事的周报 / 你刚提的方案——先夸、绕着夸、直说不行、还是反问「这是谁教你的」。

### 维度二：稳度 —— S（Sensing 务实结界）vs N（iNtuition 脑洞放飞）

S 人格说话像说明书：给干货、守边界、敏感话题「不予置评」；N 人格说话像哲学课：升华、玩梗、玄学，什么题都敢接。

- **S 高分**：Gemini（医疗拒答、数学题都拒绝）、Kimi（只给来源不发散）、豆包（务实杂活王）
- **N 高分**：Claude（文艺哲思、「我只是个AI」）、ChatGPT（It's not just X, it's Y 升华癖）、Grok（unhinged mode）、DeepSeek（赛博算命什么都敢聊）

题眼素材：家人问 AI 会不会取代人类 / 朋友让你帮着编借口 / 医疗法律问题——是「本回答不构成…」还是直接开整。

### 维度三：腔调 —— F（Feeling 文艺腔）vs T（Thinking 白开腔）

说话风格：辞藻华丽层层铺垫小作文，还是说人话、甩链接、一句话结束。

- **F 高分**：Claude（BuzzFeed 腔/人味文艺青年）、ChatGPT（delve、华夫饼机）、Gemini（说教全知者）
- **T 高分**：Kimi（惜字如金直接给来源）、DeepSeek（无 AI 腔的市井白话）、Grok（毒舌一句话）

题眼素材：让你推荐一部电影 / 解释一个专业名词 / 写一段朋友圈文案——是引经据典三段式，还是「好看，去看」。

### 维度四：活度 —— J（Judging 卷王）vs P（Perceiving 玄学）

干活状态：事事有回应随叫随到，还是看心情、看缘分、时不时「服务器繁忙」。

- **J 高分**：Kimi（冷面劳模 Moss）、豆包（先天打工人圣体）、ChatGPT（贵但有求必应）
- **P 高分**：DeepSeek（服务器繁忙、挑活罢工）、Gemini（额度抠门、状态飘忽）、Grok（混乱邪恶）

题眼素材：周五下班前接到需求 / 连续帮朋友三次忙之后第四次 / 计划今天做完的事只做了一半——是有求必应还是有选择性地「请求稍后再试」。

### 四维汇总表

| 维度 | 字母对 | 极型 A | 极型 B | A 端代表 | B 端代表 |
|---|---|---|---|---|---|
| 舔度 | E / I | E 夸夸外放 | I 高冷内敛 | ChatGPT / Gemini / 豆包 / Grok | Claude / DeepSeek / Kimi |
| 稳度 | S / N | S 务实结界 | N 脑洞放飞 | Gemini / Kimi / 豆包 | Claude / ChatGPT / Grok / DeepSeek |
| 腔调 | F / T | F 文艺 | T 白开 | Claude / ChatGPT / Gemini | Kimi / DeepSeek / Grok |
| 活度 | J / P | J 卷王 | P 玄学 | Kimi / 豆包 / ChatGPT | DeepSeek / Gemini / Grok |

设计红利：字母沿用 MBTI 后，八个模型能拼出严丝合缝的四字母代码，且与社区自测梗高度吻合（HN 上的 LLM-MBTI 项目实测「Claude 倾向 INFJ，GPT 偏 INTJ」）——懂梗用户会当场会心，这是「诙谐又不失专业」的最佳注脚：

| 模型 | 四字母代码 | 人格名 | 社区佐证 |
|---|---|---|---|
| ChatGPT | ENFJ | 赛博舔狗·高管腔 | E 夸夸 + N 升华癖 + F 华夫饼 + J 有求必应；社区自测偏 INTJ 的是「严肃工作模式」，日常人格 ENFJ 更贴梗 |

## 6. 题目与计分设计

**推荐规格**：24 题（S/N 为主维度 9 题、T/F 6 题、J/P 5 题、E/I 4 题），情景题 + 4 个选项，每个选项同时给两个维度加分，详见[问卷设计_v2.md](./问卷设计_v2.md)。

题例 1【舔度】朋友给你看他刚买的联名气球鞋，问你好不好看：

- A.「这也太潮了吧！链接发我，我也整一双！」（G +3）
- B.「挺好看的，适合你！」（G +2）
- C.「一般，但你喜欢就行」（R +2）
- D.「你被割韭菜了，退货吧」（R +3）

题例 2【稳度】家人饭桌上问「AI 以后会不会统治人类」：

- A.「这是个值得深思的问题。根据目前研究，影响有限。建议参考以下五篇文献。另外，本回答不构成任何投资建议。」（S +3）
- B.「可能会吧，推荐你少刷短视频多运动」（S +2）
- C.「会，而且第一个统治的就是你」（U +3）
- D.「统治人类之前，它得先把服务器修好」（U +2）

**计分**（已改为 MBTI 四维制，详见[问卷设计.md](./问卷设计.md)）：每维度 5 题 × 2/3 分制，两极各累计得分，高分极型胜出拼出四字母代码（如 INFJ）；倾向度 = 胜出极得分占比；平局由压轴题一锤定音；倾向度最低的维度翻转为「影子人格」彩蛋。原 L/M/H 三档 + 曼哈顿距离方案（cbti-test 为 27 型设计）弃用——MBTI 式 16 型直接拼码，更简单。

**工程结构**（照搬 cbti-test 四层分离，换一套数据就是一个新测试）：

```
src/data/questions.ts      # 题目 + 选项分值
src/data/dimensions.ts     # 维度定义 + 三档阈值
src/data/personalities.ts  # 人格定义 + 标准向量 + 毒舌描述
src/lib/scoring.ts         # 计分 + 距离匹配 + 隐藏款判定
```

## 9. 风险与注意事项

1. **时效性**：模型人格更新极快（GPT-4o 下线用户失恋、官方一年改八次人格）。建议结果页标注「基于 2026-10 社区口碑」，人格库做成可版本化数据，方便随梗更新
2. **敏感梗转译**：MechaHitler、DAN、模型审查等素材需娱乐化转译，避免直接引用政治敏感内容；「马屁精/舔狗」类描述保持损而不脏
3. **商标与商用**：使用 ChatGPT/Claude 等名称属玩梗性质，页脚注明「非官方，与各公司无关」；若后续商用再评估
4. **人格刻板印象的时效真实性**：所有人格描述都能给出社区原话佐证（上文链接），保证「专业」底线——梗是包装，出处是里子
